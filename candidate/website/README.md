# TRV Trading Desk — project showcase

This is a responsive static portfolio page for the simulated trading desk. It uses plain HTML, CSS and JavaScript; no build step or package installation is needed.

## Preview locally

From the project root, run:

```bash
python -m http.server 8000 --directory website
```

Then open <http://localhost:8000>. You can also open `index.html` directly, though serving the directory behaves more like a hosted site.

## Publish

Upload this `website/` directory to a static hosting service, or configure a static host to use `website/` as its publish directory. The page is independent of the trading containers and does not connect to an exchange. See the parent project README for how to run the simulated desk locally.
